# Glossary

| Term | Definition |
| --- | --- |
| API Gateway | The application API boundary through which clients request platform operations |
| Control plane | Services and definitions that decide desired state, policy, and orchestration |
| Worker plane | Compute and service infrastructure that executes requested workloads |
| Cluster | A coordinated group of machines or services, commonly Kubernetes or OpenStack infrastructure |
| Node | A machine that participates in a cluster or workload environment |
| Pod | The smallest deployable Kubernetes workload unit |
| Tenant | A customer, team, or organizational isolation boundary |
| Workspace | OrcaCloud's application-level team or project container |
| Workspace binding | Mapping from a workspace and environment to an OpenStack project, region, and quota set |
| Policy | Rules governing identity, authorization, network access, or operational behavior |
| Volume | Persistent block storage exposed to workloads through the storage layer |
| Region | A logical OpenStack location or service domain used for tenancy and placement |
| Project | OpenStack's authorization and resource-isolation container |
| Provisioned resource | An audited record of an infrastructure resource created through the platform |
| GitOps | Operating model where desired state is version controlled and reconciled through automation |
| Observability | Metrics, logs, traces, dashboards, and alerts used to understand system behavior |
